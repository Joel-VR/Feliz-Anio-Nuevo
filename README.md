# 🎆 Año Nuevo - Cuenta Regresiva

Un sistema interactivo de cuenta regresiva diseñado para celebrar la llegada del Año Nuevo. El proyecto cambia automáticamente a una pantalla de celebración festiva el 1 de enero de cada año y vuelve a la cuenta regresiva al finalizar el día.

## ✨ Características

- **🎉 Celebración Automática**: El 1 de enero de cada año, el sistema activa una pantalla especial con fuegos artificiales y mensajes festivos.
- **⏳ Cuenta Regresiva**: Muestra el tiempo restante (días, horas, minutos y segundos) para el próximo Año Nuevo.
- **📱 Responsivo**: Diseño optimizado para dispositivos móviles, tablets y escritorio.
- **🎨 Efectos Visuales**: Fondo animado con partículas y fuegos artificiales generados mediante Canvas API.
- **📅 Personalización**: Permite cambiar manualmente la fecha objetivo y el mensaje a través de un modal integrado.
- **🔊 Audio Opcional**: Incluye efectos de sonido que se pueden activar con un botón.

## 🛠️ Tecnologías utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Diseño moderno con Flexbox, Grid y animaciones personalizadas.
- **JavaScript (Vanilla)**: Lógica de la cuenta regresiva, manipulación del DOM y efectos de Canvas.

## 🚀 Instalación y Uso

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/anionuevo.git
   ```
2. Abre el archivo `index.html` en tu navegador preferido.

No requiere dependencias externas ni servidores complejos, funciona directamente como un sitio estático.

## 📁 Estructura del Proyecto

- `index.html`: Estructura principal del sitio y modal de configuración.
- `style.css`: Estilos visuales, variables de color y diseño responsivo.
- `app.js`: Lógica del contador, efectos de fuegos artificiales y gestión de fechas.
